# The book "Python API Development Fundamentals" uses several packages that have undergone major breaking changes since publication. Below is a detailed breakdown of the updated packages, the specific functions/imports that will break, and their modern replacements.

# ### 1. Flask-JWT-Extended (Major Breaking Changes)

# The book uses version `3.20.0`, but the current version (4.x+) completely overhauled its API.

# **Old Import (from Book):**
# ```python
# from flask_jwt_extended import jwt_optional, jwt_refresh_token_required, get_raw_jwt
# ```

# **New Import (Current Version):**
# ```python
# from flask_jwt_extended import jwt_required, get_jwt, get_jwt_identity
# ```

# **Key Changes to Implement:**
# *   **`@jwt_optional`**: Replace with `@jwt_required(optional=True)` .
# *   **`@jwt_refresh_token_required`**: Replace with `@jwt_required(refresh=True)` .
# *   **`get_raw_jwt()`**: Replace with `get_jwt()`. This returns the full JWT payload dictionary .
# *   **Blacklist to Blocklist**: All references to "blacklist" in the configuration and callbacks have been renamed to "blocklist". The decorator is now `@jwt.token_in_blocklist_loader` and it requires **two arguments** (`jwt_header`, `jwt_payload`) .

# ### 2. Flask-Uploads (Unmaintained)

# The book uses `Flask-Uploads==0.2.1`, which has not been updated since 2016 and is incompatible with modern Flask.

# **New Package to Install:**
# ```bash
# pip install Flask-Reuploaded
# ```
# It is a drop-in replacement, meaning you can keep using `from flask_uploads import ...` without changing your import names .

# **Key Change to Implement:**
# *   **`patch_request_class`**: This function was removed. Instead of using it in `app.py`, set the maximum upload size via Flask's native configuration:
#     ```python
#     app.config['MAX_CONTENT_LENGTH'] = 10 * 1024 * 1024  # 10 MB
#     ```
#     .

# ### 3. Marshmallow (Version 4 Breaking Changes)

# The book uses `marshmallow==2.19.5`. The current version is 4.x, which introduced significant changes to how schemas are defined and executed.

# **Key Changes to Implement:**
# *   **`@post_dump(pass_many=True)`**: The `pass_many` parameter has been renamed to `pass_collection` .
# *   **`Schema.load()`**: It no longer silently fails when a generator is passed; ensure you are passing a dictionary .
# *   **`Schema.dump().data`**: The `.data` attribute is deprecated/removed in v4. You should now call `schema.dump(obj)` directly, which returns the serialized dictionary.
# *   **`context`**: The context parameter is deprecated in v3.24 and removed in v4.0 .

# ### 4. Webargs (Version 8.x)

# The book uses `webargs==5.4.0`. The current version is 8.x.

# **Key Changes to Implement:**
# *   **`@use_kwargs`**: The syntax has changed slightly. You should now use it as `@use_kwargs({"visibility": fields.Str(load_default="public")})` (note the use of `load_default` instead of `missing`) .
# *   **Parser**: The import path `from webargs.flaskparser import use_kwargs` remains correct.

# ### 5. Passlib (Maintenance Status)

# The book uses `passlib==1.7.1`. The original project is largely unmaintained.

# **New Package to Install:**
# You can use the maintained fork `libpass`, which keeps the `passlib` import name:
# ```bash
# pip install libpass
# ```
# Your existing code `from passlib.hash import pbkdf2_sha256` will continue to work .

# ### 6. Flask-Migrate

# The book uses `Flask-Migrate==2.5.2`. The current version is 4.x.

# **Key Changes to Implement:**
# *   This package is generally backward compatible for the basic commands (`flask db init`, `migrate`, `upgrade`).
# *   Ensure your `alembic` version is >= 1.9 as required by newer Flask-Migrate versions .
